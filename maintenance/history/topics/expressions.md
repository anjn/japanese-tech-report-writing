# 空疎な表現と不自然な比喩

[現行のレビュー規範](../../../references/review.md) ／ [判断索引](../../decisions.md)

<a id="x05"></a>

### X05：不自然な比喩の点検方法

適用段階：レビュー時。

出典：翻訳調の比喩と擬人化の禁止、末尾の判定方法。

> 判定の目安は二段である。
> まず、その述語を初めて見る読者が字義どおりの動作（運ぶ、開く、住む）を想像しうるなら、翻訳調の比喩を疑う。
> 次に、動作の主体と対象を具体語で言い直せるか試す。
> 言い直せるなら、その言い直しをそのまま書く。
> 言い直せないなら、その文は指す内容が特定できていないので、主張として成立していない。削るか、内容を確定させてから書き直す。

- 目的：意識せず混入した不自然な比喩を見つけ、具体化する。
- 採否案：修正して採用。
- 理由：字義どおりの動作を想像できても、定着した自然な表現はある。言い換えが難しいことだけで、主張が成立しないとは断定できない。
- 修正案：文脈や分野の慣用を踏まえ、主体・対象・処理を読み手が特定できるかを確認する。曖昧なら具体的に言い換える。意味が確定できなければ確認事項として残し、根拠なく削除や補作をしない。A03、A04に統合する。

初回の合意は[第18回](../rounds.md#round-18)に記録。

<a id="a01"></a>

### A01：予告と総括

適用段階：レビュー時。

出典：LLM っぽい表現の禁止、「予告と総括」。

> **予告と総括**：「重要なのは〜である」「本章では〜を扱う／探求する」「ここでは〜について見ていく」「まとめると」「要するに」（直前の言い換えだけのとき）、「〜に他ならない」

- 目的：内容のない前置きや反復を減らす。
- 採否案：条件付き採用。
- 理由：読者が読む範囲を選ぶための案内や、長い説明の要点整理には役割がある。L01と整合させる。
- 修正案：内容のない予告や、直前の言い換えだけの総括は省く。対象範囲や読む順序の案内、長い説明の要点整理など、読み手の負荷を減らすものは残す。定型句の有無だけで判定しない。

初回の合意は[第4回](../rounds.md#round-4)に記録。

<a id="a02"></a>

### A02：空虚な形容・動詞

適用段階：レビュー時。

出典：LLM っぽい表現の禁止、次の2項。判断をA02a（形容）とA02b（動詞）に分け、同じ方針を提案する。

> **空虚な形容**：「不可欠」「核心的」「鍵となる」「根本的な」（主張の中身を説明せず強調だけする）、「多角的」「包括的」「総合的」（何をどう見たかを書かない）

> **空虚な動詞**：「掘り下げる」「深掘りする」「言語化する」（何をどう書いたかを示さず終わる）、「触れる」「言及する」（一段落で済ませるだけ）

- 目的：強調や姿勢だけで内容を伝えたように見せる表現を減らす。
- 採否案：A02a、A02bとも採用。
- 理由：語自体ではなく、具体的な内容を示さない使い方を避ける規範として残す。
- 適用例：「多角的に検証しました」なら、実際に検証した観点を示す。不明な観点は補わず、確認するか内容のない修飾を省く。

初回の合意は[第4回](../rounds.md#round-4)に記録。

<a id="a03"></a>

### A03：無生物主語と擬人化

適用段階：レビュー時。

出典：翻訳調の比喩と擬人化の禁止、「無生物主語構文の直輸入」から抜粋。

> 日本語では、人か処理を主体に戻すか、「〜から分かる」「〜に含まれる」の形に言い直す。

- 目的：意思や認識があるような表現によって、実際の処理や観測結果が曖昧になることを防ぐ。
- 採否案：条件付き採用。
- 理由：「サーバーが応答を返す」など、主体と動作が明確な技術表現はそのまま使える。無生物主語を一律に排除すると説明が回りくどくなる。
- 修正案：不自然な擬人化や、確認できない意思・認識を示す表現は、処理や観測できる事実に直す。主体と動作が明確な通常の技術表現は維持する。確認できる内容がない場合は、事実を作って置き換えない。

初回の合意は[第4回](../rounds.md#round-4)に記録。

<a id="a04"></a>

### A04：比喩を具体化する際の意味の保持

適用段階：レビュー時。

出典：翻訳調の比喩と擬人化の禁止、「英語慣用句の直訳」の例。

> 悪い例：「推敲の軸が露出する」（expose）。良い例：「推敲の軸が線形に取り出せる」。

- 目的：不自然な直訳を、意味の分かる具体的な説明に変える。
- 採否案：修正して採用。
- 理由：修正例は「線形」という新しい性質を加えており、元の文だけではその根拠を判断できない。
- 修正案：不自然な比喩を、文脈で確認できる対象や動作に置き換える。比喩の解消を理由に、新しい性質や根拠を付け足さない。意図が特定できない場合は確認するか、未確定として扱う。
- 条件付きの例：文脈が評価基準の明確化を指すなら「推敲で使う評価基準が明確になる」と書く。元の意図が常にこれだと決めつけない。

初回の合意は[第4回](../rounds.md#round-4)に記録。

<a id="v04"></a>

### V04：話し言葉による曖昧な評価

適用段階：レビュー時。

出典：翻訳調の比喩と擬人化の禁止、「研究者の話し言葉の混入」の本文。

> **研究者の話し言葉の混入**：機械学習の口頭議論で流通する動詞（「効く」「刺さる」「筋がいい」など）は、話し言葉としては通じるが、書き言葉の技術文書では俗語である。効果や見込みの内容を具体的に書く。

- 目的：効果や評価の内容を読み手の推測に任せない。
- 採否案：採用。
- 理由：効果や見込みを具体化する指針として残す。言い換えに必要な事実がなければ確認し、効果量や理由を作らない。実際の発言を引用する箇所は、引用の文言を勝手に直さない。

初回の合意は[第14回](../rounds.md#round-14)に記録。

<a id="s01"></a>

### S01：姿勢だけを宣言する言葉

適用段階：レビュー時。

出典：LLM っぽい表現の禁止、「正面から系」。

> **正面から系**：「正面から扱う」「正面から回収する」「正面から見る／書く／立てる」——中身の代わりに姿勢だけを宣言する

- 目的：何を説明したかを示さない、姿勢だけの修飾を減らす。
- 採否案：採用。
- 理由：実際の論点や操作を直接述べる規範として残す。語の文字列ではなく、このような使い方を点検する。

初回の合意は[第17回](../rounds.md#round-17)に記録。

<a id="s04"></a>

### S04：接続や評価だけの文

適用段階：レビュー時。

出典：冗長の排除、第6項。

> 接続や評価のためだけの文（「それ自体はよいことである」など）を置かない。

- 目的：情報を増やさないつなぎや評価を減らす。
- 採否案：条件付き採用。
- 理由：判断理由を明確にする評価や、長い説明の関係を整理する文は役立つ。
- 修正案：情報や論理関係を加えないつなぎ、根拠のない評価は省く。結論に必要な評価は、何を基準に判断したかが分かる形で残す。接続や評価を担う文という理由だけで削らない。

初回の合意は[第17回](../rounds.md#round-17)に記録。

<a id="s05"></a>

### S05：発想のメタな紹介と著者の弁明

適用段階：レビュー時。

出典：冗長の排除、第8・第9項。

> 読者が抱きそうな発想を、メタな枠取り（「ここまでの話には自然な続きがある」「〜という発想である」）で紹介しない。その発想自体を直接書く。読者の疑問なら疑問文のまま書いてよい（「その保守も任せればよいのではないだろうか」）。

> 「本書もそれを否定しない」のような、著者の立場の弁明や断りを書かない。事実の記述（「〜に書かせる場合が多い」）だけを置く。

- 目的：論点を直接述べ、内容のない前置きや自己弁護を減らす。
- S05a（発想そのものを述べる）：採用。E02と合わせ、読者の反応を演じず、必要な問いや提案を直接述べる。
- S05b（著者の弁明を省く）：条件付き採用。判断の記録に必要な立場、責任範囲、選択理由は残す。立場の説明を、裏付けのない一般的事実に置き換えない。

初回の合意は[第17回](../rounds.md#round-17)に記録。

<a id="z01"></a>

### Z01：案内・強調・比喩

適用段階：レビュー時。

出典：概要から書く。

> 「本レポートでは〜を述べる」のような構成の予告は書かない。概要に結論が入っていれば足りる。

出典：視点と語り。

> イ形容詞の終止に「です」を続けた文（「難しいです」「多いです」）を書かない。これは文体の規則ではなく、文の流れの破綻の兆候である。イ形容詞を裸で言い切る必要が生じるのは、その文が前後から孤立しているからであり、流れている文章なら「〜は難しく、…」と文が続くか、「〜でしょう」「〜である」で受けられる。出現したら文末だけ取り繕わず、前後の流れごと書き直す。ナ形容詞の「〜です」（「重要です」）は対象外。

出典：演出の抑制。

> 「重要なのは〜である」のような前置きで主張を予告しない。主張をそのまま書く。ただし、主張の様式を宣言する前置き（「標語として言い換えれば」など）は使ってよい。

出典：演出の抑制。

> 「AではなくBだった」という対句の決め台詞を多用しない。軽い補足や評価は括弧書きで添えてよい。

出典：演出の抑制。

> 慣用表現をひねった言い回し（「知識を体に入れる」など）や、指す内容が一意に決まらない比喩（「報告の外側に世界が広がっている」など）を使わない。平易な動詞でそのまま言う（「身につく」「気付く機会が減る」）。

出典：翻訳調の比喩と擬人化の禁止。

> **英語慣用句の直訳**：英語の技術文では carry / open / expose / live / land などの比喩的用法が慣用句として定着しており、比喩として意識されない。これを日本語の対応語に直訳すると、日本語では慣用化していないため、字義どおりに読める奇妙な生きた比喩になる。

出典：翻訳調の比喩と擬人化の禁止。

> **無生物主語構文の直輸入**：英語では無生物主語の他動詞文が普通だが、そのまま日本語にすると、モデル、データ、ベクトル、損失といった抽象物が意思を持って振る舞う擬人化になる。日本語では、人か処理を主体に戻すか、「〜から分かる」「〜に含まれる」の形に言い直す。

- 採否案・適用方針：条件付き採用・既存項目へ統合。案内と強調はA01・S01、否定対比はE01・T03、比喩と擬人化はA03・A04・X05、文末はA05に対応づける。意味のある案内や自然な表現は残し、内容のない演出を減らす。原文にある生成原因の説明は、一般的な因果として断定せず、点検すべき表現の傾向として整理する。

初回の合意は[第19回](../rounds.md#round-19)に記録。
