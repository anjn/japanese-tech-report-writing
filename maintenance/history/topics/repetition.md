# 重複と参照の負担

[現行のレビュー規範](../../../references/review.md) ／ [判断索引](../../decisions.md)

<a id="k05"></a>

### K05：参照先の確認

適用段階：レビュー時。

出典：論証の厳密さ、第8項。

> 「次節で扱う」と前方に逃がした論点は、本当にそこで回収されることを確認する。回収しない伏線を張らない。

- 目的：参照先に必要な説明がなく、読者が探し回ることを防ぐ。
- 採否案：採用。
- 理由：構成変更や削除の後も、参照先と内容の対応を確認する。D04の参照位置と合わせて使う。

初回の合意は[第12回](../rounds.md#round-12)に記録。

<a id="l01"></a>

### L01：主張の反復

適用段階：レビュー時。

出典：読者の体力を前提にする、第1項。

> 一つの主張は、一か所で一度だけ書く。本文、表、グラフ、注記で同じ内容を繰り返さない。

- 目的：新しい情報のない反復を減らす。
- 採否案：条件付き採用。
- 理由：概要と本文、単独で参照する節では、再掲が読み返しを減らす。一律禁止は利用場面に合わない。
- 修正案：同じ役割の箇所で同じ主張を言い換えて繰り返さない。概要で要点を伝える場合や、独立して参照する箇所で理解・実行を助ける場合は、必要な内容を再掲する。

初回の合意は[第1回](../rounds.md#round-1)に記録。

<a id="l05"></a>

### L05：文字数と冗長さ

適用段階：レビュー時。

出典：冗長の排除、第5項。

> 冗長さは文字数や文数で判定しない。短文化と一文化は、動機、対象、操作、その同一性、因果、条件が順読みで明示されたまま保てる場合に限る。これらを読者の推論に委ねる圧縮はせず、必要な反復と長さを残す。

- 目的：短縮によって読み手の推論や記憶の負担を増やさない。
- 採否案：採用。
- 理由：合意した良い文章の定義に直接対応する。L01〜L04を判断する基準にもなる。
- 修正案：内容は維持する。再構築時の表現整理は、採否とは別に示す。

初回の合意は[第1回](../rounds.md#round-1)に記録。

<a id="d04"></a>

### D04：前方参照の位置

適用段階：レビュー時。

出典：段落と論証の構成、最終項。

> 「後の章で扱う」のような前方参照は、論証が一段落した位置（段落末・節末）に置く。論証の途中に挟んで流れを切らない。

- 目的：参照の案内で説明を中断しない。
- 採否案：条件付き採用。
- 理由：補足への案内は段落末などに置けるが、今の理解に必要な参照先はその場で案内するほうがよい。
- 修正案：補足への参照は、説明を妨げにくい位置に置く。理解や作業にその場で必要な情報は、その場で示すか具体的な参照先を案内する。重要な前提を「後で扱う」だけで先送りしない。

初回の合意は[第10回](../rounds.md#round-10)に記録。

<a id="n03"></a>

### N03：説明直後の要約

適用段階：レビュー時。

出典：冗長の排除、第3項。

> 場面を描写した直後に、その内容を要約し直さない。意味づけの一文（「このような作業は、ほぼ完全に任せられる」など）だけを置く。

- 目的：直前の説明を言い換えるだけの反復を避ける。
- 採否案：条件付き採用。
- 理由：長い説明や複雑な例の後には要点整理が役立つ。意味づけの追加も、根拠がなければ不要な一般化になる。
- 修正案：短い説明をそのまま言い換えるだけの要約は省く。長い説明の要点を整理する場合は残す。解釈や評価を加える場合は、説明した内容がその主張を支えるか確認する。A01とK04に統合して扱う。

初回の合意は[第13回](../rounds.md#round-13)に記録。

<a id="q01"></a>

### Q01：数値の再掲の削除

適用段階：レビュー時。

出典：書き上げ後の重複の点検、第1項。

> 主要な数値をすべて拾い、それぞれが何か所に出ているかを数える。概要の表や図に載せた数値が、本文に再び出ていれば、本文の側を削る。本文では、数値を並べ直さず、表から読み取るべきこと（差、順位、理由）だけを書く。差を述べるために基準値を出す必要があるときは、差だけを書き、基準値を再掲しない。

- 目的：数値の読み上げによる重複を減らす。
- 採否案：修正して採用。
- 理由：L01、L03に合わせる。基準値を省くと比較を理解しにくくなる場合がある。出現回数だけで削除しない。
- 修正案：数値の再掲は、その場の比較や判断に必要かで点検する。表の全数値を読み上げる反復は省くが、必要な基準値や主要結果は残す。再掲した値、単位、条件の一致も確認する。

初回の合意は[第16回](../rounds.md#round-16)に記録。

<a id="q02"></a>

### Q02：説明と確認事項の重複

適用段階：レビュー時。

出典：書き上げ後の重複の点検、第3項。

> 説明の節に書いた内容が、手順の確認事項に再び出ていないかを見る。出ていれば、手順の側に残し、説明の側を削る（手順は削らない）。

- 目的：操作に必要な情報を残しながら重複を減らす。
- 採否案：条件付き採用。
- 理由：説明と実行時の確認には別の役割がある。L01、L04に合わせ、一律に説明を削らない。
- 修正案：説明と手順で同じ内容を示す場合は、それぞれの役割を確認する。理由を理解する説明と、操作時の確認事項は両方残してよい。役割のない反復だけを省く。

初回の合意は[第16回](../rounds.md#round-16)に記録。

<a id="q03"></a>

### Q03：同じ主張と必要な反復の区別

適用段階：レビュー時。

出典：冗長の排除、第1項。

> 同じ主張を言い換えて繰り返さない。一つの主張は一度だけ書く。題材が直前と同じでも、その文が加えている命題が違えば繰り返しではない。列挙の各項が同じ論理的地位であることを示す枠語の反復や、定義の直後に適用条件や限定を足す文も、主張の繰り返しではない。

- 目的：無用な言い換えと、意味を持つ反復・補足を区別する。
- Q03a（一つの主張は一度だけ）：条件付き採用。L01に統合し、概要や独立して参照する節での再掲を認める。
- Q03b（新しい命題・枠語・適用条件の区別）：採用。同じ語の出現だけで重複と判断しないための具体的な規範として残す。

初回の合意は[第16回](../rounds.md#round-16)に記録。

<a id="q04"></a>

### Q04：補足を置く位置

適用段階：両方。

出典：読者の体力を前提にする、第2項。

> 読者がまだ必要としていない情報は、後ろに回す。補足は、必要になる箇所の直前に置く。

- 目的：必要になる前に詳細を覚え続ける負担を減らす。
- 採否案：条件付き採用。
- 理由：必須の前提、局所的な補足、詳細資料では適した位置が異なる。P02、D04に合わせる。
- 修正案：理解や実行に必要な前提は、必要になる前に示す。局所的な補足は該当箇所の近くに置き、一部の読者だけが必要とする詳細は後段や別資料に分ける。結論を誤読させる条件を、補足として後ろへ追いやらない。

初回の合意は[第16回](../rounds.md#round-16)に記録。
